# UPSC ZONE AI

A standalone landing-page design concept for an AI-powered UPSC Civil Services preparation platform. The page presents study tools, exam stages, current-affairs content, pricing, mentors, team information, success stories, and FAQs.

## Preview

Open `index.html` directly in a modern web browser. No build step or package installation is required.

Alternatively, serve the project locally from its root directory:

```bash
python -m http.server 8000
```

Then visit <http://localhost:8000>.

## Project structure

```text
.
└── index.html    # Landing page markup and embedded styles
```

## Notes

- This is a static UI mockup; it does not include a backend or working account, signup, or payment flows.
- The page uses Google Fonts (Inter and Source Serif 4), so those fonts require an internet connection. System fallback fonts are used if they cannot be loaded.
- Navigation within the page uses section anchors.
